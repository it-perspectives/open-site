# Changelog

## 0.1.0 — Initial specification

Initial OpenSite draft:

- Required page inventory with stable IDs, URL paths, and path parameters.
- Typed search parameters, defaults, examples, enums, and constraints.
- Required ARIA roles and structured locators for every component, including nested components.
- JSON Schema Draft 2020-12, equivalent YAML/JSON examples, and QA documentation.
- Framework-independent locator descriptors and a fixed ARIA role vocabulary.
- Node.js parser, semantic validator, query checker, URL builder, CLI, and TypeScript declarations.
- Conformance tests, CI, and local release artifact preparation.
- Page states, component expectations, access policies, form constraints and cases.
- Interface variants, local reusable components, QA metadata, transitions and negative URL outcomes.
- Snackbar messages, actions, dismissal, lifetime, timing checks, stacking and localization.
- Pure data resolution and form-value validation APIs with TypeScript declarations.
- Tag-driven GitHub releases, versioned release notes and source archives, and guarded atomic deploy command.
